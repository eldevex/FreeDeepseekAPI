# DeepSeek Session Reset

Управление сессиями локального прокси FreeDeepseekAPI.

## Когда использовать

### 1. Пользователь хочет новый чат (основной сценарий)
- «Начни новый чат», «сбрось сессию», «начнём заново», «start fresh».
- Пользователь переключился на другую тему и не хочет тянуть старый контекст.
- После смены аккаунта DeepSeek.

### 2. Новые сообщения попадают в старый чат
- Пользователь отправляет сообщение, а оно уходит в предыдущий диалог.
- Причина — прокси переиспользует `session.id` для того же агента.

### 3. Ошибка `context_length_exceeded`
- Прокси (**начиная с патча от 27.09.2026**) сбрасывает сессию сам, когда DeepSeek отвечает «контекст переполнен».
- Если пользователь всё равно видит эту ошибку — можно сбросить вручную.

### 4. Пользователь просит показать, какие сессии есть
- «Какие у меня активные чаты?», «что сейчас в сессиях?», «сколько чатов открыто?».

## Что делает сброс

Обнуляет `session.id` для указанного агента. **Локальная история агента сохраняется** (последние 15 сообщений), но следующий запрос создаёт **новый удалённый чат** DeepSeek. То есть контекст диалога не теряется, а просто начинается «новая страница» в веб-интерфейсе DeepSeek.
