1 Подготовка Termux

Откройте Termux и установите необходимое:

pkg update && pkg upgrade -y
pkg install nodejs-lts git curl -y
node -v

Убедитесь, что Node.js версии 18 или выше. Если ниже — обновите:

pkg install nodejs-lts
Примечание: FreeDeepseekAPI не имеет npm-зависимостей, поэтому npm install не требуется. Проект работает «из коробки» на Node.js 18+.

2 Клонирование репозитория

Клонируйте форк:

cd ~
git clone https://github.com/eldevex/FreeDeepseekAPI.git
cd FreeDeepseekAPI

Проверьте, что всё на месте:

ls -la

Вы должны увидеть server.js, package.json, deepseek-auth.json (или .example), папку chrome-extension/ и др.

3 Установка расширения Chrome

Для получения auth-файла используется расширение DeepSeek Auth Exporter. Его нужно установить в браузер на компьютере (или в браузер на телефоне, поддерживающий расширения Chrome, например Kiwi Browser).

3.1 Скачайте расширение

Вариант А — через git:

git clone https://github.com/eldevex/FreeDeepseekAPI.git
# Расширение находится в папке:
# FreeDeepseekAPI/chrome-extension

Вариант Б — скачайте ZIP-архив репозитория и распакуйте его. Папка расширения — chrome-extension.

3.2 Загрузите расширение в Chrome

  1. Откройте chrome://extensions.
  2. Включите Режим разработчика.
  3. Нажмите Загрузить распакованное расширение.
  4. Укажите папку chrome-extension.
  5. Расширение появится в списке. Закрепите его на панели.
Важно: расширение работает только на chat.deepseek.com. Убедитесь, что вы вошли в свой аккаунт DeepSeek.

4 Получение auth-файла

Откройте https://chat.deepseek.com и войдите в аккаунт.

  1. Нажмите на иконку DeepSeek Auth Exporter.
  2. Нажмите кнопку Collect from Tab.
  3. Расширение соберёт токен, cookie, hif_dliq, hif_leim.
  4. Нажмите Download File — сохранится deepseek-auth.json.
Если каких-то полей не хватает: перезагрузите вкладку DeepSeek (F5), отправьте сообщение в чате (например, «ok») и снова нажмите Collect from Tab.
Безопасность: файл содержит доступ к вашему аккаунту DeepSeek. Не публикуйте его.

5 Копирование auth-файла в Termux

После скачивания файл окажется в папке загрузок. Скопируйте его в проект:

cp ~/storage/downloads/deepseek-auth.json ~/FreeDeepseekAPI/deepseek-auth.json

Если файл называется иначе (например, deepseek-auth (1).json):

cp ~/storage/downloads/deepseek-auth*.json ~/FreeDeepseekAPI/deepseek-auth.json

Проверьте:

ls -la ~/FreeDeepseekAPI/deepseek-auth.json
cat ~/FreeDeepseekAPI/deepseek-auth.json
Если папка ~/storage/downloads не существует: выполните termux-setup-storage и подтвердите доступ.

6 Запуск сервера

Перейдите в папку проекта и запустите:

cd ~/FreeDeepseekAPI
npm start

Появится меню:

1 — authorize / refresh the DeepSeek login
2 — show models and statuses
3 — start the proxy
4 — exit

Введите 3 и нажмите Enter. Сервер запустится на http://localhost:9655.

Для запуска без меню (в фоне):

NON_INTERACTIVE=1 npm start
Сервер работает. Не закрывайте это окно Termux — прокси должен оставаться запущенным.

9 Патч: авто-сброс при переполнении контекста

По умолчанию FreeDeepseekAPI при ошибке context_length_exceeded пытается ретраить запрос в тот же чат, что бесполезно (контекст на сервере DeepSeek уже разросся). Патч заставляет сбросить сессию и создать новый чат — с сохранением локальной истории.

9.1 Бэкап

cp ~/FreeDeepseekAPI/server.js ~/FreeDeepseekAPI/server.js.bak

9.2 Правка

nano ~/FreeDeepseekAPI/server.js

Через Ctrl+W найдите строку:

const contextTooLong = isContextTooLongError(modelError);

Сразу после неё вставьте:

                // При переполнении контекста сбрасываем remote-чат (session.id=null),
                // следующий retry создаст новый. Локальная история агента сохраняется.
                if (contextTooLong && session.id) {
                    console.log(`${agentTag} context too long — resetting remote chat (msg#${session.messageCount} -> new)`);
                    session.id = null;
                    session.parentMessageId = null;
                    session.createdAt = null;
                    session.messageCount = 0;
                    session.deltaMsgCount = 0;
                    session.deltaBoundary = null;
                    session.deltaPrefixHash = null;
                    session.deltaToolNames = null;
                    session.repairHash = null;
                    session.repairAt = 0;
                    session.repairCount = 0;
                    persistSessions();
                }

Сохраните: Ctrl+O → Enter → Ctrl+X.

9.3 Перезапуск

pkill -f "node server.js"
cd ~/FreeDeepseekAPI
NON_INTERACTIVE=1 npm start
После патча длинные диалоги больше не упираются в лимит: при переполнении контекста создаётся новый чат DeepSeek, локальная память не теряется.

10 Skill /reset для Kai 9000

Kai 9000 — это AI-агент с sandbox-окружением, который умеет устанавливать навыки (skills) прямо из GitHub-репозитория по URL. Skill — это файл SKILL.md с YAML frontmatter и инструкциями: Kai читает его и учится вызывать shell-команды по триггерам-фразам или по команде /<name>.

Что получится: вы пишете в чат Kai «начни новый чат DeepSeek» или /reset, и Kai сам вызывает POST http://localhost:9655/reset-session — сессия сбрасывается, следующий запрос идёт в новый чат DeepSeek.

10.1 Создайте папку skill в репозитории

Kai сам ищет файл SKILL.md в репозитории. Положим его в отдельную папку:

cd ~/FreeDeepseekAPI
mkdir -p skill
nano skill/SKILL.md

10.2 Вставьте содержимое

---
name: reset
description: Сбросить сессию FreeDeepseekAPI и начать новый чат DeepSeek. Вызывать при фразах — новый чат, начни новый чат, создай новый чат, давай новый чат, начнём заново, начни с нуля, начни с чистого листа, сбрось сессию, сбрось чат, сбрось DeepSeek, сбрось контекст, очисти сессию, очисти чат, обнули чат, обнули контекст, забудь контекст, перезапусти сессию, reset deepseek, reset chat, start fresh, new chat, deepseek stuck, мы застряли, сообщения идут в старый чат. Также при ошибке context_length_exceeded.
---

# Reset DeepSeek Session

## Точные URL

| Действие | Метод | URL |
|---|---|---|
| Список сессий | GET | `http://localhost:9655/v1/sessions` |
| Сброс сессии | POST | `http://localhost:9655/reset-session?agent=<id>` |

Путей `/v1/reset-session` и `/v1/sessions/reset` **не существует** — они дают 404.
